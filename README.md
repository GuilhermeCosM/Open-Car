# Open Car - Sistema Web de Locação de Veículos

Projeto desenvolvido em Python utilizando Flask com foco em locação de veículos através de uma aplicação web.

## Sobre o Projeto

O Open Car é um sistema web de locação automotiva criado com o objetivo de praticar desenvolvimento backend e frontend utilizando Python e Flask.

A aplicação simula um sistema de aluguel de carros, permitindo que usuários visualizem veículos disponíveis, realizem reservas e utilizem funcionalidades de autenticação.

Durante o desenvolvimento foram aplicados conceitos importantes de Programação Orientada a Objetos, arquitetura MVC, rotas, templates e manipulação de dados.

## Funcionalidades

- Cadastro de usuários
- Login de usuários
- Visualização dos veículos disponíveis
- Sistema de reserva de carros
- Navegação entre páginas
- Interface web responsiva
- Organização utilizando MVC

## Como Executar

Clone o repositório:

```bash
git clone https://github.com/GuilhermeCosM/Open-Car.git

Acesse a pasta do projeto:

```bash
cd Open-Car
```

Instale as dependências:

```bash
pip install -r requirements.txt
```

Execute a aplicação:

```bash
python app.py
```

Abra no navegador:

```bash
http://127.0.0.1:5000
```
